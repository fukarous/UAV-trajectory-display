一、算法总览

本系统采用26 方向 A* 算法在三维栅格空间中搜索无人机航线。算法在标准 A* 基础上融合了五类约束，构成一个多目标优化问题：在满足安全约束的前提下，最小化飞行代价。

整体优化目标
$$\min_{P} \; \sum_{i=1}^{n} \Big[ \underbrace{\|p_i - p_{i-1}\|}_{\text{距离成本}} + \underbrace{\delta_z\,|p_i^z - p_{i-1}^z|}_{\text{垂直爬升惩罚}} + \underbrace{N(p_i)}_{\text{噪音成本}} \Big]$$

其中 $P = (p_0, p_1, \dots, p_n)$ 为三维路径点序列，$p_i \in \mathbb{R}^3$。搜索受以下约束限制：

约束类型含义
禁飞区硬约束路径点与航段不得穿越任何禁飞多边形
建筑避障硬约束航段不得与建筑 AABB 包围盒相交
最低离地高度硬约束$z \geq z_{dem} + h_{min}$，保证与地面/建筑安全间距
最大离地高度硬约束$z \leq z_{dem} + h_{max}$（可选）
TKE 湍流硬约束$TKE \leq \tau$，避免进入高湍流区域
最大爬升角硬约束$|\Delta z| / \|\Delta xy\| \leq \tan(\theta_{climb})$
航向变化软约束连续转向角 $\geq \theta_{heading}$ 时禁止转向
噪音敏感区软约束靠近噪音敏感区时增加代价惩罚

二、三维搜索空间与 26 方向邻域

搜索空间以起点与终点的外接矩形为界，沿三个坐标轴按网格步长 $\Delta$ 离散化。每个节点 $p=(x,y,z)$ 的邻域为 $3\times3\times3$ 立方体中除自身外的全部 26 个方向：

26 方向邻域
$$\mathcal{N}(p) = \Big\{ p + (d_x,d_y,d_z) : d_i \in \{-\Delta,0,\Delta\},\; (d_x,d_y,d_z)\neq(0,0,0) \Big\}$$
轴对齐移动

6 个基本方向

沿 X / Y / Z 轴的单轴步进，如 $(\pm\Delta,0,0)$。平面搜索中移动代价为 $\Delta$，垂直移动代价为 $\Delta$（受爬升惩罚加权）。

对角移动

20 个对角方向

两个或三个轴同时步进，如 $(\pm\Delta,\pm\Delta,0)$、$(\pm\Delta,\pm\Delta,\pm\Delta)$。对角代价为 $k\Delta$，其中 $k=\sqrt{2}$ 或 $\sqrt{3}$。

方向集合在搜索前按朝向目标优先级排序——计算每个方向向量与目标方向向量的点积，点积越大越优先展开，使搜索更早趋向终点。

三、代价函数与多约束

从起点到节点 $p$ 的实际代价 $g(p)$ 由距离成本、垂直惩罚与噪音成本三部分组成：

实际代价 $g(p)$
$$g(p) = g(p_{prev}) + \underbrace{\|\Delta p\|}_{\text{欧氏距离}} + \underbrace{w_z\,|\Delta z|}_{\text{垂直惩罚}} + \underbrace{N(p)}_{\text{噪音代价}}$$

其中垂直惩罚权重 $w_z = 6.0$：适度惩罚爬升/下降，鼓励平飞的同时不排斥必要时越障。

噪音代价

当路径靠近噪音敏感区（医院、学校等）时，根据水平距离 $d_s$ 与飞行高度 $h$ 施加反比惩罚：

噪音代价函数
$$N(p) = w_s \cdot \Delta \cdot \sum_{s \in S} \frac{w_s'}{h^2 + d_s^2 + 1}$$

其中 $w_s$ 为全局噪音敏感度系数，$S$ 为影响范围内的噪音敏感区集合，$w_s'$ 为各区的敏感权重。飞行越高、离区越远，代价越低。

四、启发函数与动态权重 (WA*)

启发函数 $h(p)$ 估计从节点 $p$ 到终点的剩余代价，采用动态权重策略：距离目标越远权重越大（贪婪探索），越近权重越小（精细寻路）。

动态权重启发函数
$$h(p) = \Big(1 + \frac{d}{2000}\Big) \cdot 2.5 \cdot \|xy - xy_{goal}\| \;+\; 5.0 \cdot |z - z_{goal}| \;+\; \underbrace{c \cdot \big\| (p-s) \times (g-s) \big\|}_{\text{tie-breaker}}$$

其中 $d$ 为当前节点到终点的欧氏距离。当 $d$ 很大时，权重 $1 + d/2000$ 使算法更"贪心"；靠近终点时权重趋近 1，恢复精确搜索。最后一个交叉积项作为平局打破器（tie-breaker），使算法在代价相同时优先选择贴近起终点直线的路径。

采用 A* 判定式：当当前节点距终点小于接受半径 $r_{goal}$ 时视为到达：

终点判定
$$\|p - p_{goal}\| < r_{goal} \quad \land \quad |p_z - z_{goal}| < r_{goal}$$

五、碰撞检测与空间索引

为保证实时性，建筑物、禁飞区、噪音区均预先构建桶状空间索引（Bucket Spatial Index）：将研究区划分为 $200\text{m} \times 200\text{m}$ 的格桶，每个要素被登记到其覆盖的所有桶中。查询时只需检查相关桶的邻居，大幅减少无效检测。

点与航段碰撞检测

航段 $AB$ 与建筑包围盒 $[x_{min},x_{max}]\times[y_{min},y_{max}]\times[0,z_{top}]$ 的相交检测采用Slab 法：对每个轴分别求参数区间 $[t_1,t_2]$，若三个轴区间有交集则该航段碰撞。

Slab 区间求交
$$t_1^{(i)} = \frac{lo^{(i)} - o^{(i)}}{d^{(i)}}, \quad t_2^{(i)} = \frac{hi^{(i)} - o^{(i)}}{d^{(i)}} \quad \Rightarrow \quad \bigcap_{i=x,y,z} [\min(t_1,t_2),\ \max(t_1,t_2)] \neq \varnothing$$

航段内进一步按 2 米间隔自适应采样，逐点验证离地高度与建筑避碰，防止长航段"跳过"障碍。

禁飞区判定

点是否在禁飞多边形内采用射线法（Ray Casting）：从该点水平发射射线，统计与多边形边的交点数目，奇数次为内、偶数次为外。

射线法（奇偶规则）
$$\text{inside}(p,\mathcal{R}) = \big( \#\{\text{边}\ e : \text{射线} \cap e \} \bmod 2 \big) = 1$$

实现要点：仅当边的两个端点分列测试点水平线两侧时（$(y_i > p_y) \neq (y_j > p_y)$，此时 $y_j \neq y_i$ 保证不会除零）才计算交点横坐标 $x_{int} = x_i + \frac{p_y - y_i}{y_j - y_i}(x_j - x_i)$，并去掉首尾重复的闭合顶点以避免零长度边。若对分母人为钳制 $\max(y_j - y_i, \epsilon)$，会破坏几何求交导致漏判/误判（禁飞区形同虚设）：

def point_in_poly(px, py, verts):
    inside, n = False, len(verts)
    if n > 1 and verts[0] == verts[-1]:   # 去掉重复闭合点
        verts = verts[:-1]; n = len(verts)
    for i in range(n):
        xi, yi = verts[i]; xj, yj = verts[(i+1) % n]
        if (yi > py) != (yj > py):        # 标准射线法
            x_int = xi + (py - yi) * (xj - xi) / (yj - yi)
            if px < x_int:
                inside = not inside
    return inside

六、路径后处理与平滑

A* 输出的折线路径节点密、转角硬，经过三级后处理得到可飞航线：

① Catmull-Rom 样条插值

对每三个相邻节点执行 Catmull-Rom 样条，每段插值出 3 个子点，使路径平滑连续且通过所有原始节点：

Catmull-Rom 插值公式
$$C(t) = \frac{1}{2}\Big[ (2p_1) + (-p_0 + p_2)\,t + (2p_0 - 5p_1 + 4p_2 - p_3)\,t^2 + (-p_0 + 3p_1 - 3p_2 + p_3)\,t^3 \Big]$$

② 高度平滑

对高度序列执行中值滤波（窗口 7）去除毛刺，再执行均值滤波（窗口 5）消除抖动，得到稳定平缓的垂向剖面。

③ 噪音优化

对经过噪音敏感区的路径点，将其高度提升至 $h_{max} \times 0.75$ 以上，同时限制单步爬升不超过 8m，在规避噪音的同时保持坡度可飞。

④ 安全复验

最终逐段复验整条航线：对碰撞航段尝试在 1/6~5/6 处插点并提升离地高度重新验证；若插值点全部验证失败，说明该航段可能穿过禁飞区或建筑，直接丢弃该点而非冒险接受，保证输出路径严格安全。

七、自适应网格分辨率

根据起终点直线距离自适应调整搜索网格步长，平衡精度与计算量：

起终点直线距离网格步长 $\Delta$空间索引桶场景定位
$\leq 1$ km3 m50 m高精度微操（楼间穿行）
1 ~ 5 km10 m100 m常规城市街区
5 ~ 10 km20 m200 m跨区长干线
$> 10$ km20 m250 m超远距离宏观巡航

同时终点接受半径自适应为 $r_{goal} = \max(16\text{m},\ 1.5\Delta)$，保证大步长不会跨过终点。

八、核心算法实现

以下为从工具箱中提取的关键实现，涵盖 A* 主循环、26 方向邻域生成、动态权重启发与多约束碰撞检测。

26 方向邻域生成（朝向目标预排序）

# 生成 26 方向增量，按朝向目标优先级预排序
def generate_deltas(start, goal, step, max_climb):
    climb_tan = math.tan(math.radians(max_climb))
    gv = (goal[0]-start[0], goal[1]-start[1], goal[2]-start[2])
    gl = math.hypot(*gv) or 1.0
    deltas = []
    for dx in (-step, 0, step):
        for dy in (-step, 0, step):
            for dz in (-step, 0, step):
                if dx==0 and dy==0 and dz==0: continue
                hd = math.hypot(dx, dy)                       # 水平距离
                if hd > 0 and abs(dz)/hd > climb_tan: continue  # 爬升角约束
                sl = math.hypot(dx, dy, dz)
                dot = (dx*gv[0]+dy*gv[1]+dz*gv[2])/(sl*gl)  # 朝向目标的点积
                deltas.append((dx, dy, dz, hd, dot))
    deltas.sort(key=lambda x: -x[4])          # 点积大者优先
    return deltas

A* 主循环（动态权重 WA*）

open_set = [(0, start_pt)]
came_from, g_score = {}, {start_pt: 0.0}
last_dir = {start_pt: (0,0,0)}

while open_set and iters < a_star_limit:
    iters += 1; _, cur = heapq.heappop(open_set)
    cd = math.hypot(cur[0]-end[0], cur[1]-end[1], cur[2]-end[2])

    if cd < goal_radius and abs(cur[2]-end[2]) < goal_radius:
        break                                    # 到达终点

    for dx, dy, dz, hd, _ in deltas:
        target = (round(cur[0]+dx,1), round(cur[1]+dy,1), round(cur[2]+dz,1))

        if not is_segment_valid(cur[0],cur[1],cur[2], *target):
            continue                             # 碰撞检测

        # 代价：距离 + 垂直惩罚 + 噪音
        dc = math.hypot(dx,dy,dz) + abs(dz)*6.0
        nc = noise_cost(mid_x, mid_y, mid_z) if not endgame else 0.0
        tg = g_score[cur] + dc + nc

        if tg < g_score.get(target, float('inf')):
            came_from[target] = cur; g_score[target] = tg

            # 动态权重启发
            dw = 1.0 + cd/2000.0                   # 越远越贪心
            h  = dw*2.5*math.hypot(nx-end[0], ny-end[1]) \
               + 5.0*abs(nz-end[2]) + tie_breaker
            heapq.heappush(open_set, (tg+h, target))

多约束碰撞检测（含起终点豁免）

def is_collision(x, y, z, cfg):
    # 起终点豁免：允许从起点出发、抵达终点，即使其恰在约束区边缘
    is_terminal = (abs(x-start[0])<1.0 and abs(y-start[1])<1.0) or \
                  (abs(x-end[0])<1.0 and abs(y-end[1])<1.0)
    gz = sample(dem, x, y, 0)
    if z < gz + cfg['min_agl']:            return True   # 离地过低
    if cfg['max_agl'] and z > gz + cfg['max_agl']:
        return True                            # 离地过高
    if wind and not is_terminal and sample(wind,x,y) > tke_threshold:
        return True                            # TKE 湍流过强
    if not is_terminal and check_nofly_point(x, y): return True  # 禁飞区
    for obs in query_aabb(bldg_index, x, y, x, y, bucket):
        if xmin<=x<=xmax and ymin<=y<=ymax and z<=obs['top']:
            return True                          # 建筑避障
    return False

航段安全验证（自适应采样 + Slab 求交）

def is_segment_valid(x1,y1,z1, x2,y2,z2, cfg):
    if is_collision(x1,y1,z1) or is_collision(x2,y2,z2): return False
    if intersects_building(x1,y1,z1,x2,y2,z2): return False
    dist = math.hypot(x2-x1, y2-y1, z2-z1)
    samples = max(1, int(dist/2.0)+1)      # 每 2m 采样一次
    for i in range(1, samples):
        t = i/samples
        sx = x1+t*(x2-x1); sy = y1+t*(y2-y1); sz = z1+t*(z2-z1)
        gz = sample(dem, sx, sy, 0)
        if sz < gz + cfg['min_agl']: return False    # 离地过低
        for obs in query_aabb(bldg_index, sx, sy, sx, sy, bucket):
            if sz <= obs['top']: return False    # 建筑遮挡
    return True

Catmull-Rom 平滑

def catmull_rom(p0, p1, p2, p3, t):
    t2, t3 = t*t, t*t*t
    def interp(v0, v1, v2, v3):
        return 0.5 * ((2*v1) + (-v0+v2)*t
                 + (2*v0-5*v1+4*v2-v3)*t2
                 + (-v0+3*v1-3*v2+v3)*t3)
    return (interp(p0[0],p1[0],p2[0],p3[0]),
            interp(p0[1],p1[1],p2[1],p3[1]),
            interp(p0[2],p1[2],p2[2],p3[2]))
